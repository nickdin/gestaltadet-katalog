# C-095 använder

**Definition:** relationstyp som anger att ett arkitekturelement nyttjar den funktionalitet ett annat arkitekturelement tillhandahåller

## Anmärkning

Relationen går från det nyttjande elementet till det tillhandahållande.

## Motsvarigheter

Motsvarar ArchiMates Serving, riktningen vänd.

Motsvarar Usage i Unified Modeling Language (UML), aktörens streck till användningsfallet, Include mellan två användningsfall och kopplingen (Connector) från en komponents krävda gränssnitt till ett givet. Beslut 29.
