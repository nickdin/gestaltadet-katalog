# C-095 använder

**Definition:** relationstyp som anger att ett arkitekturelement nyttjar den funktionalitet ett annat arkitekturelement tillhandahåller

## Anmärkning

Relationen går från det nyttjande elementet till det tillhandahållande. Motsvarar ArchiMates Serving, riktningen vänd.
