# C-028 Bedömningsutrymme

**Definition:** del av valet som ett styrmedel lämnar kvar till den som ska följa det

## Anmärkning

Samma utrymme sett från andra hållet är det som den som prövar måste bedöma. Lämnas inget är prövningen binär. Lämnas riktningen men inte valet måste någon bedöma om valet ligger i riktningen. Lämnas alla val på vägen prövas bara utfallet.

Regeln ([[C-020 Regel]]) lämnar inget utrymme i vad som ska gälla; det är det som skiljer den från principen ([[C-018 Princip]]), som lämnar valet kvar. Det omdöme som kan krävas för att avgöra om ett läge råder, om särskilda skäl föreligger, är prövningens, inte utrymme som styrmedlet lämnar. ADR 0037.
