# C-194 Hjälp

**Definition:** hur ett värdeerbjudande hjälper människor med ett behov, röjer dess hinder och ger dess vinst

## Anmärkning

Hjälpen säger hur erbjudandet röjer behovets hinder ([[C-192 Hinder]]) och ger dess vinst ([[C-193 Vinst]]). Den står i värdeerbjudandets ([[C-148 Värdeerbjudande]]) text, en per behov erbjudandet möter ([[C-153 möter]]): ett begrepp, ingen elementtyp. Ett behov utan hjälp är passningen synliggjord: det erbjudandet inte gör.

Hjälpen bedöms efter värden ([[C-195 Värde]]), de mätbara nyttor erbjudandet består av. Hjälpen är det erbjudandet gör för behovet, värdet är den egenskap mottagaren bedömer det efter.

Motsvarar ValueItem i Business Architecture Core Metamodel (BACM), verksamhetens tro att mottagaren värderar ett visst utfall (beslut 27), och Pain Reliever och Gain Creator i Value Proposition Canvas. Hette Svar till beslut 28, som bytte termen för att ordet ska gå att förstå utan definitionen.

## Exempel

för behovet att veta om stödet beviljas: beslutet kommer inom en vecka och skälen står med.
