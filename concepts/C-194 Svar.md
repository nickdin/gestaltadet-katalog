# C-194 Svar

## Anmärkning

Ett begrepp, ingen elementtyp: svaret står i värdeerbjudandets ([[C-148 Värdeerbjudande]]) text, ett per behov erbjudandet möter ([[C-153 möter]]), och säger hur erbjudandet röjer behovets hinder ([[C-192 Hinder]]) och ger dess vinst ([[C-193 Vinst]]). Ett behov utan svar är passningen synliggjord: det erbjudandet inte gör. Motsvarar ValueItem i Business Architecture Core Metamodel (BACM), verksamhetens tro att mottagaren värderar ett visst utfall; passningens mått, BACM:s ValueCharacteristic, väntar på ett måttbegrepp. ADR 0027.

## Exempel

för behovet att veta om stödet beviljas: beslutet kommer inom en vecka och skälen står med.
